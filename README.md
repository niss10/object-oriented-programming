# Object-Oriented Programming Practice

This repository is dedicated to my journey of learning and practicing **Object-Oriented Programming (OOP)** concepts across different programming languages.  
I am focusing on building a strong foundation in OOP and applying these principles to solve problems using **OOP design patterns**.

## Goals
- Understand the core pillars of OOP.
- Implement OOP in multiple programming languages.
- Practice solving problems with **design patterns** such as Singleton, Factory, Observer, Strategy, etc.
- Develop a habit of writing clean, modular, and reusable code.

## Structure
The repository may include:
- Code snippets and examples in different languages.
- Implementations of classic design patterns.
- Problem-solving exercises using OOP techniques.

## Purpose
This is purely a **learning and practice repository**.  
The main goal is to strengthen my understanding of object-oriented design and improve my ability to build well-structured software.
